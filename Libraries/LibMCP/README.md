# `LibMCP` (`Libraries/LibMCP`)

> Embedded HTTP + JSON-RPC 2.0 Model Context Protocol (`MCP`) server for Ladybird (`feat/extensions-dnr-and-dom-tools` / `main`).  
> See [Fork Architecture and Capabilities](../../Documentation/ForkArchitectureAndCapabilities.md), [Automation README](../LibWebView/Automation/README.md), and [Extensions README](../LibWebView/Extensions/README.md).

## 1. Architecture and Files

`LibMCP` embeds a local MCP server inside Ladybird's `Hub` (`WebView::Application`) backend with no external runtime dependencies:

| File | Responsibility |
| :--- | :--- |
| [`Forward.h`](Forward.h) | Forward declarations (`MCPServer`, `MCPDelegate`, `TabInfo`, `ToolCallResult`) |
| [`MCPDelegate.h`](MCPDelegate.h) | Pure-virtual delegate interface (`TabInfo`, `SkillMatchHint`, `CredentialMatchHint`, `ProtocolCallResult`, `OnProtocolCallComplete`) bridging `MCPServer` requests to `WebView::Application` |
| [`MCPServer.h`](MCPServer.h) | Public server lifecycle and notification broadcast helpers (`create`, `local_port`, `auth_token`, `session_id`, `broadcast_notification`, `notify_resource_updated`, `close_all_sse_streams`, `sse_client_count`) |
| [`MCPServer.cpp`](MCPServer.cpp) | Loopback TCP listener, HTTP + SSE (`GET /mcp`) transport/validation, JSON-RPC 2.0 + SEP-2640 + resource subscription router, schema definitions for 58 tools |
| [`CMakeLists.txt`](CMakeLists.txt) | Builds `LibMCP` linking `PRIVATE` targets `LibCore`, `LibHTTP`, and `LibURL` |

## 2. Quickstart

1. **Launch Ladybird with MCP enabled**:

   ```powershell
   # Windows
   .\Build\release\bin\Ladybird.exe --mcp
   # Linux / macOS
   ./Build/release/bin/Ladybird --mcp
   ```

   Pass `--mcp-token <token>` for a fixed token, or read the generated 64-hex-character token from stdout (`MCP server listening on http://127.0.0.1:7331/mcp (token: ...)`). In the UI, click **Copy Config** on the bottom `MCPBanner` to copy `{"url":"http://127.0.0.1:7331/mcp","headers":{"Authorization":"Bearer <token>"}}` to the clipboard, and click **Allow This Tab** (or use the tab context menu -> **Allow MCP Access**) on any user tab you want to expose.

2. **Initialize a client session**:

   ```json
   POST http://127.0.0.1:7331/mcp
   Authorization: Bearer <token>
   Content-Type: application/json

   {"jsonrpc":"2.0","id":1,"method":"initialize","params":{}}
   ```

## 3. Transport, Authentication, and Protocol (`58` Tools + `9` Protocol Methods + SSE)

- **Endpoint & JSON-RPC 2.0 (`MCPServer::Connection`)**: Serves `POST /mcp` (`Content-Type: application/json`), persistent `GET /mcp` SSE streams (`Accept: text/event-stream`, returning `200 text/event-stream; charset=utf-8`, `Cache-Control: no-cache`, `Connection: keep-alive`, `: connected\n\n`, and `25 s` `: keepalive\n\n`; missing `Accept` returns `406 Not Acceptable`), and `DELETE /mcp` (closes active SSE streams, clears subscriptions and the session's ephemeral container ID, cleans up ephemeral containers with no remaining active views — preserving any container that still has open tabs — and returns `200 {"ok":true}`); non-`/mcp` paths return `404`; other HTTP methods return `405` (`Allow: GET, POST, DELETE`). `initialize` negotiates `protocolVersion` `"2025-03-26"` or `"2026-07-28"` (with `tools.listChanged: false`, `resources.subscribe: true`, `resources.listChanged: false`, `logging: {}`, and `extensions["io.modelcontextprotocol/skills"].directoryRead: true`), returns `instructions`, and sets header `Mcp-Session-Id: <uuid>`. Notifications (no `"id"`) return `202 Accepted`; `"id": null` returns JSON-RPC error `-32600` (`Invalid Request`).
- **Protocol & Discovery JSON-RPC Methods (9) + SSE Push**: `ping`, `server/discover`, `skills/list`, `skills/get`, `resources/list`, `resources/subscribe`, `resources/unsubscribe`, `resources/read` (skills + `ladybird://notifications`, `ladybird://notifications/tab/<id>`, `ladybird://notifications/origin/<origin>`), and `resources/directory/read`, plus server-pushed SSE `notifications/resources/updated` and `notifications/message`.
- **58 Registered Tools (`tools/list` / `tools/call`, top-level `additionalProperties: false`)**:

| Group | Count | Tools |
| :--- | :---: | :--- |
| Tabs & Navigation | 12 | `list_tabs`, `get_active_tab`, `list_containers`, `create_container`, `open_tab` (ephemeral `agent-ephemeral-*` container by default when unfiltered — cookies & web storage in memory, HTTP disk cache subject to non-private network/cache settings — or first listed container when `--mcp-allowed-containers` is set, or explicit `container_id`), `migrate_tab_container`, `switch_tab`, `close_tab`, `navigate`, `reload`, `go_back`, `go_forward` |
| DOM, Input, Notifications & Diagnostics | 22 | `get_accessibility_tree`, `get_dom_tree`, `get_page_source`, `find_elements`, `click` (elements, coordinates, `button`, `click_count`, `modifiers`), `type_text` (`use_keyboard` trusted mode), `get_page_snapshot` (`@e1` handles across open Shadow DOM & same-origin frames, modal prioritization, optional `root_selector`), `press_key` (`modifiers`), `scroll`, `wheel`, `hover` (elements or coordinates), `drag` (coordinates/deltas, `modifiers`), `upload_file`, `list_upload_files`, `select_option`, `wait_for`, `list_notifications`, `wait_for_notification`, `get_console_logs`, `get_network_requests`, `eval_js`, `take_screenshot` (paired Base64 PNG `image` + `text` `security_envelope` visual warning) |
| Automation Flows | 8 | `list_flows`, `get_flow`, `save_flow`, `delete_flow`, `run_flow`, `list_flow_runs`, `get_flow_run`, `cancel_flow_run` |
| Extensions | 6 | `list_extensions`, `install_unpacked_extension`, `set_extension_enabled`, `reload_extension`, `remove_extension`, `inject_extension` |
| WebMCP & Site Manifests | 3 | `list_page_tools`, `call_page_tool`, `inspect_site_manifests` |
| Agent Skills | 4 | `list_skills`, `read_skill`, `save_skill` (`--mcp-allow-skill-write`), `delete_skill` (`--mcp-allow-skill-write`) |
| Blind Credential Vault | 3 | `list_credentials`, `fill_credential`, `login_with_credential` |

  For compatibility with clients that serialize nested objects as strings, `save_flow` (`flow`) and `call_page_tool` (`arguments`) accept both JSON objects and JSON-encoded strings. `TabInfo` exposes `container_id`, `mcp_access_mode` (`blocked`, `read_only`, `same_origin`, `full`), `matching_skills`, and `matching_credentials`. In container discovery, when no ephemeral container has been created yet and `--mcp-allowed-containers` is unset, `list_containers` marks `"agent"` with `is_default_mcp: true` while also returning top-level `ephemeral_default` to signal that `open_tab` without `container_id` will create/reuse an ephemeral `agent-ephemeral-*` container (when `--mcp-allowed-containers` is set, the first listed container becomes the effective default). On first profile initialization, Ladybird also seeds the built-in `ladybird-agentic-guide` Agent Skill into `<profile>/skills/` (discoverable via `list_skills`, `read_skill`, SEP-2640 `skills/list`, and `about:skills`).

## 4. Security Boundaries and Known Caveats

- **Transport Controls**: Binds strictly to `127.0.0.1` (`MCPServer::create`); enforces a `30 s` HTTP read timeout (`408 Request Timeout`); rejects duplicate `Host`/`Authorization` headers (`400`), non-loopback `Host` headers outside `localhost`/`127.0.0.1`/`[::1]` (`403`), and any request carrying an `Origin` header (`403`); validates `Authorization: Bearer <token>` in constant time (`401`); sets `X-Content-Type-Options: nosniff`, `Connection: close` / `Cache-Control: no-store` on RPC responses, and `Connection: keep-alive` / `Cache-Control: no-cache` on SSE streams.
- **Request Cap (`4 MiB` Body / `64 KiB` Headers), Session ID & Connection/SSE Caps**: `HTTP::HttpRequest::from_raw_request` caps individual request-line/header tokens at `65,536` bytes while permitting request bodies up to `4 MiB` (`MAX_REQUEST_BYTES`), returning `413` above either bound. Any present `Mcp-Session-Id` header (including empty) is validated in constant time against the active server session (`404` on mismatch); `MCPServer::on_new_client` caps total active sockets at `64` (`503`), `open_sse_stream` caps concurrent SSE streams at `8` (`503`) with non-blocking writes that drop slow consumers, and `resources/subscribe` caps tracked URIs at `128` (`MAX_RESOURCE_URI_LENGTH = 512`).
- **Per-Tab Access Modes, Kill Switch, Egress Guard & Private-Tab Isolation**: User tabs are excluded (`blocked`) from `list_tabs` and rejected by tool calls until opted in via the Qt `MCPBanner` selector or tab context menu -> **MCP Access** (`Blocked`, `Read-Only`, `Same-Origin`, `Full`); `ViewImplementation::update_displayed_url` automatically reverts to `Blocked` on privileged `about:`/`resource:` URLs and locks `Same-Origin` onto the first committed `http:`/`https:` origin. Reading non-`"agent"` `http:`/`https:` tabs arms the session **Cross-Tab / Egress Taint Guard**, requiring UI confirmation (with post-prompt TOCTOU origin/permission verification) before `open_tab`, cross-origin `navigate`, unapproved-origin DOM/JS mutations, `call_page_tool`, or `FlowRunner` cross-origin steps (without globally whitelisting read source origins across tabs). `MCPBanner`, `about:agent`, and `MCPServer::set_paused(bool)` provide a live **Pause Agent / Resume Agent** Kill Switch blocking `tools/call` (returns an MCP tool result with `isError: true`) and blocking `skills/*`, `resources/read`, and `resources/directory/read` with JSON-RPC `-32001`, while canceling active MCP `FlowRunner` runs, pending approvals, queues, and waits, and suppressing SSE broadcasts (preserving `resources/list`, `resources/subscribe`, `resources/unsubscribe`, active SSE connections, and egress taint state). Live metrics and tool/shield audit logs are viewable on **`about:agent`** (**Shield** button on `MCPBanner`).
- **Anti-Injection Content Shield (`MCPContentShield`) & Visibility Hardening**: Readout payloads (`get_page_snapshot`, `get_page_source`, `get_dom_tree`, `get_accessibility_tree`, `get_console_logs`, `get_network_requests`, `run_flow`/`list_flow_runs`/`get_flow_run`, `list_page_tools`, `call_page_tool`, `list_notifications`, `wait_for_notification`, and `ladybird://notifications*`) plus internal navigation-wait results (such as the `wait_for_navigation` option of `login_with_credential`, which is not a standalone registered MCP tool) strip invisible Unicode Tags, BiDi overrides, zero-width/variation-selector/soft-hyphen/Braille-blank characters (`512 KiB` signal scan cap); `get_page_source` additionally strips `<!-- ... -->` and HTML5 `--!>` comments and wraps `framed_source` in a per-response CSPRNG `boundary_nonce`. `get_page_snapshot` filters ancestor/element hidden (`display:none`, `visibility:hidden|collapse`, `opacity<=0.01`, `hidden`, `aria-hidden="true"`, `font-size<=0.1px`, `transparent` color, `color===backgroundColor`, zero-area `clip`/`clip-path`, and off-screen) decoys and builds `text_excerpt` strictly via a visible-node `TreeWalker`.
- **Native Human-in-the-Loop Qt Approvals (TOCTOU-Hardened)**: `upload_file` (both direct tool calls and MCP `FlowRunner` `upload_file` steps), `install_unpacked_extension`, `fill_credential` (`password`/`totp`), `login_with_credential`, consequential/destructive `call_page_tool` (server-inspected via `listTools`), and egress-guarded actions require interactive `QMessageBox` confirmation (`60 s` fail-closed timeout; re-checks pause state, permissions, `SameOrigin` bounds, and unchanged tab origin before execution; cancels cleanly on tab close, revocation, pause, or `Hub::View` teardown).
- **Command Queue Timeout (`35 s`) & Recovery**: `Application::dispatch_next_mcp_content_command` waits `35 s` (exceeding `WebDriverConnection`'s `30 s` `script_timeout`) and calls `ViewImplementation::cancel_webdriver_content_command` on timeout or revocation (`fail_mcp_requests_for_view`) so `m_webdriver_input_command_running` is cleared cleanly and queued input commands never wedge. `WebDriverConnection::run_command` supersedes any stale in-flight command instead of hitting `VERIFY(!m_current_command_id.has_value())`.
- **`drag`, `wheel`, Coordinate `click`/`hover`, `take_screenshot`, & `upload_file` Guards**: `Application::drag`, `Application::take_screenshot`, `Application::wheel`, coordinate `click`, and coordinate `hover` reject inactive or hidden tabs immediately (`switch_tab` required). `Application::upload_file` resolves `<input type="file">` (including via `<label>` or enclosing Shadow DOM upload triggers for `ref`/`selector` JS resolution and direct `element_id` via `get_element_tag_name` + `get_element_attribute`), checks tab access and human UI approval before touching disk, and delegates to `resolve_and_validate_upload_path` -> `validate_mcp_upload_path` using `Application::effective_upload_directory()` (defaults to browser-configured Upload Directory `<Videos>/Ladybird Uploads`, overridden by `--mcp-upload-dir`; rejects `\0`/`\r`/`\n` control characters, UNC `\\`/`//` paths, `..`, filesystem roots, leaf symlinks via `FileSystem::is_link`, canonicalization failures on `FileSystem::real_path`, directories/non-regular files, paths outside the active upload directory, and credential/profile paths including `.ssh`, `.gnupg`, `.aws`, `.kube`, `.azure`, `/.config/gcloud/`, `/ladybird/profiles/`, `/appdata/local/ladybird/`, `/appdata/roaming/ladybird/`, `/.local/share/ladybird/`, `/library/application support/ladybird/`, `.env*`, private keys, `Cookies`, `Login Data`, `Web Data`, `SAM`, `NTUSER.DAT`). `WebDriverConnection::element_send_keys_impl` enforces a cumulative `512 MiB` total upload cap with weak-pointer/command-ID guards; both canonicalized and un-resolved relative directory segments are checked with `FileSystem::is_link` (note `FileSystem::real_path` does not expand NTFS junctions on Windows). `list_upload_files` exposes non-hidden regular filenames and sizes inside `effective_upload_directory()`.
- **Extension & Skill Write Gates**: `Application::install_unpacked_extension` requires `--mcp-allow-extension-install`; `Application::save_skill_tool` and `delete_skill_tool` require `--mcp-allow-skill-write`.
- **CLI Policy Controls**: `eval_js` and MCP `FlowRunner` `eval` steps are **disabled by default** (`--mcp-allow-eval-js` required to enable; `--mcp-disable-eval-js` overrides to off). WebMCP `call_page_tool` runs with document-ID pinning, single-use inspection tickets, and native Qt confirmation for consequential/destructive tools (disable via `--mcp-disable-webmcp`). `--mcp-disable-screenshots` blocks `take_screenshot` and MCP flow `screenshot` steps, `--mcp-redact-screenshot-media` enforces `redact_media: true` (temporarily hiding `<img>`, `<picture>`, `<video>`, `<canvas>`, `<svg>`, and CSS backgrounds during capture, while `take_screenshot` also emits a paired `text` `security_envelope` visual warning alongside `image/png` pixels), and `--mcp-allowed-containers`, `--mcp-allowed-domains`, `--mcp-blocked-domains`, `--mcp-auto-approve` (`--headless` mode only, ignored in GUI, and recorded in `about:agent` audit log), and `--mcp-max-tabs` (default `16`) govern runtime boundaries.
- **Blind Credential Vault & Quarantine**: Encrypted via AES-256-GCM (`--mcp-vault-passphrase`, `LADYBIRD_VAULT_PASSPHRASE`, Windows DPAPI `master.dpapi`, or POSIX `0600` `master.key`), with origin/container pinning, `<input type="password">` + `action`/`formaction` checks, active-document-change taint quarantine across inspection/eval/snapshot/flow steps, and `scrub_secrets_from_string` output redaction. Privileged `about:*` pages (such as `about:vault` and `about:skills`) are excluded from MCP access.
- **WebMCP Phase 1 (`document.modelContext` / `navigator.modelContext`)**: `inject_webmcp_shim_if_needed` injects post-commit via `CanonicalTraversable::did_activate_history_entry` -> `did_start_load_for_extensions` on `http:`/`https:` MCP-allowed non-private tabs, exposes frozen (`Object.freeze`) `modelContext` globals (`configurable: false`) on Secure Contexts (`window.isSecureContext`, `https:`, `localhost`, `127.0.0.1`, `[::1]`), freezes `window.__ladybirdWebMCP` (`api`), captures built-in references (`Map`, `Set`, `Array.from`, `Object.defineProperty`, `Object.freeze`, `Object.prototype.hasOwnProperty`, `JSON.parse`, `JSON.stringify`), scans `document` and open `shadowRoot` `form[toolname]` elements, marks tools `untrustedContentHint: true`, and delegates `consequentialHint` / `destructiveHint` confirmation to the native Qt approval gate. The call is pinned to a native document ID and a single-use inspection ticket. The renderer checks the current registration or form and its execution metadata before invoking it. Remaining caveat: injection still arrives asynchronously in the page's Main World (so early inline `<head>` scripts may run first).

## 5. Testing

Run the unit test suite (`24` test cases):

```powershell
./Build/release/bin/TestLibWebView[.exe] --suite TestMCPAutomation
```
